# 飞书单窗口 Demo 验证场景

运行前先按[飞书单窗口说明](../tools/FEISHU_SINGLE_WINDOW_DEMO.md)配置独立的测试机器人和本地状态目录。以下场景使用专用测试聊天。

| 场景 | 预期结果 |
| --- | --- |
| 为一个已确认的本地 Codex 会话配对 | 指定机器人和聊天取得当前面板的输入权。其他聊天发来的消息被忽略。 |
| 从飞书发送一条文本 | 输入送到已绑定面板，写入回执只表示终端收到输入。 |
| 用独立命令行 Demo 转发测试附件 | 附件保存到专用状态目录，绑定终端收到本地路径。 |
| 窗口、会话或连接代次变化 | 旧目标不能继续接收绑定输入。 |
| 从菜单切回桌面 | 当前窗口释放桥接输入权，本地终端可以继续使用。 |

在仓库根目录运行 `python -m unittest discover -s tools -p "test_*.py"` 可以用模拟传输检查消息处理、配对、离线队列和回执。
